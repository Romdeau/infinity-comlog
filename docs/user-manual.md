# User Manual

Welcome to Infinity Comlog. This utility helps you manage Infinity N5 army lists, inspect roster details, analyze list composition, track game sessions, and reference common rules at the table.

## Army builder

Open **Army Builder**, or choose **Build an army** in Army Lists.

1. Choose a faction or sectorial and name the army.
2. Select 100, 200, or 300 points. **Edit** accepts any positive whole-number limit. Base SWC is the limit divided by 50; profiles with bonus SWC increase that allowance.
3. Search by unit, weapon, equipment, or skill. Expand a unit to compare its loadouts. Choose a destination combat group, then **Add** a loadout.
4. Use **Add combat group** and each roster entry's group selector to arrange your force. Assign separately purchased Servant or Cyberplug peripherals to an eligible controller. Moving a controller moves its attached peripherals; moving a Posthuman moves its proxies together.
5. Resolve the roster checks, then **Save to library**. In Army Lists, assign the saved list to A or B to use the roster, analysis, and game tools.

The builder checks points, SWC, exactly one Lieutenant, faction availability, shared character restrictions, a maximum of 15 troopers and 10 per combat group, profile dependencies, peripheral controllers, and Posthuman composition. Unspent points are allowed. The catalogue excludes optional mercenary mode, Spec-Ops, Reinforcement pools, and disabled alternate profiles. Included pilots and peripherals stay with their purchased loadout. Fireteams are formed during deployment and are not assigned by this editor.

Draft changes save automatically on this device. Reducing the limit keeps the roster and reports any overspend. Changing faction or clearing the roster asks before removing selections. Use **Edit a copy** in the library to revise a built list; saving creates a new library entry and preserves the original and any active assignments. Built lists refresh from their profile IDs when measurements or army data change. They do not have an Infinity Army export code; use List View to print them.

Rules references: [Army list](https://infinitythewiki.com/Army_List), [Peripheral](https://infinitythewiki.com/Peripheral), and [G: Jumper](https://infinitythewiki.com/G:_Jumper).

## Army Lists

Use **Army Lists** to paste Infinity Army codes and assign them to active List A or List B.

- Imported lists are saved locally so they can be reassigned without pasting the code again.
- Active List A and List B must use the same sectoral and points value.
- The saved library can assign a stored list to either active slot or delete it from local storage.
- The copy button on an active list copies its army code when one is available.

## List View

Use **List View** to inspect the active lists in a roster-focused layout.

- Tabs switch between active List A and List B.
- Combat groups show unit cards and unit detail dialogs.
- The weapon chart summarizes weapon modes and range bands.
- The print action opens the browser print dialog for a cleaner roster view.

## List Analysis

Use **List Analysis** to review composition signals before or during a match.

- Order pool cards show regular, irregular, Tactical Awareness, and impetuous counts.
- Specialist breakdowns count hackers, doctors, engineers, paramedics, Forward Observers, Chain of Command, and Specialist Operatives.
- Charts show points invested by troop type.

## Getting Started

1. Import or assign at least one active army list.
2. Open **Game Sequence** and create or select a session.
3. Pick the ITS mission from the dropdown. This sets up the classified count and mission objectives.
4. Choose the list you are using for the session.
5. Record who won the Lieutenant Roll and what they chose: Initiative or Deployment.
6. Follow setup reminders, including special deployment notes such as Infiltration or Hidden Deployment.

## Turn Tracking

The tracker is divided into 3 game rounds. Each round contains:

- **Your Turn / Opponent Turn**: Detailed phases such as Tactical, Orders, States, and End of Turn.
- **Round Scoring**: At the end of both players' turns, check off or increment objectives scored during the round.

## Scoring

The **Finalise Scoring** section provides a summary of your performance:

- **Objective Points (OP)**: Calculated from mission objectives, round objectives, end-game objectives, and classifieds.
- **Victory Points (VP)**: Enter final survived or killed points manually.
- **Tournament Points (TP)**: Calculated from OP difference and total OP.

## Attacker & Defender Roles

Some missions, such as *Critical Intervention*, assign specific roles.

- The **Attacker** is always the player who takes the first player turn.
- The **Defender** takes the second player turn.

The app will dynamically update your objectives based on these roles once the turn order is decided.

## References

- **Order Reference** provides quick table-side reminders for turn phases, common order categories, and related actions.
- **Hacking Programs** groups hacking programs by compatible device and shows key labels from the app metadata.

## Settings

Use **Settings** to switch measurement units and refresh locally saved lists against the current data files.

- Measurement units affect displayed movement, range, and distance values.
- Re-importing local lists uses each saved raw army code when one is available.

## Tips
- Tap checkboxes to complete steps.
- Use "Done" overrides if you want to skip sub-steps but mark a whole section as finished.
- Imported lists and game sessions are stored in this browser's local storage.
